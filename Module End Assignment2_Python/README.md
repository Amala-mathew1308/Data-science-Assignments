Employee Data Analysis
1. Project Overview:
This project focuses on analyzing an employee dataset from ABC company using Python. The objective is to explore employee distribution, age groups, salary expenditure and the relationship between age and salary.

2. Dataset Description:
The dataset contains 458 employee records with information such as:

Team
Position
Age
Salary
College
Height
3. Data Preprocessing:
The following preprocessing steps were performed:

Inspected the dataset and checked its structure.
Identified missing values in different columns.
Replaced the incorrect values in the Height column with randomly generated numbers between 150 and 180, as instructed.
Identified 84 missing values in College and 11 missing values in Salary.
Retained the missing values without replacement.
4. Analysis Tasks:

Task 1: Determine the distribution of employees across each team and calculate the percentage split relative to the total number of employees.

Calculated the number of employees in each team.
Calculated the percentage distribution relative to the total workforce.
Represented the results using a bar chart.
Insight: New Orleans Pelicans has the highest employee count, with 19 employees (4.15% of the total workforce).

Task 2: Segregate employees based on their positions within the company.
Grouped employees based on their positions.
Calculated the employee count and percentage for each position.
Visualized the distribution using a bar chart.
Insight: SG has the highest employee count (102), followed by PF (100). Position C has the lowest employee count (79).

Task 3:Identify the predominant age group among employees.
Divided employees into different age groups.
Calculated the number of employees in each age group.
Visualized the distribution using a bar chart.
Insight: The 20–25 age group is predominant, with 198 employees (43.23% of the workforce).

Task 4:Discover which team and position have the highest salary expenditure.
Calculated total salary expenditure for each team.
Calculated total salary expenditure for each position.
Represented the results using bar charts.
Insight: Salary expenditure varies across teams and positions.

Task 5: Investigate if there's any correlation between age and salary, and represent it visually.
Calculated the correlation coefficient between age and salary.
Used a scatter plot to visualize the relationship.
Insight: The scatter plot shows variations in salary across different age groups. The correlation coefficient was used to investigate the linear relationship between age and salary.

5. Visualizations
The project includes:

Bar chart – Employee distribution across teams.
Bar chart – Employee distribution by position.
Bar chart – Employee distribution by age group.
Bar charts – Salary expenditure by team and position.
Scatter plot – Relationship between age and salary.

7. Conclusion
This project helped explore employee distribution across teams, positions and age groups, analyze salary expenditure and investigate the relationship between age and salary using Python data analysis and visualization techniques.
